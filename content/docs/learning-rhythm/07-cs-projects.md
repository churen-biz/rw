## 读原理不等于会工程，更不等于懂系统 {#why-build}

计算机科学自学有一条与数学截然不同的铁律：

**数学：读定义 → 做题 → 写证明。**

**CS：读原理 → 实现 → 实验 → 发现问题 → 回到理论。**

你可以在不写一行内核代码的情况下，背出「虚拟内存用页表映射」——直到 malloc lab 里一次错误的 `sbrk`、一次 double free、一次碎片化，才会真正理解**堆管理在系统抽象栈中的位置**。你可以看完 Sipser 里停机问题的证明——直到你写过一个解释器却造不出万能停机判定器，才会把「不可判定」从符号变成**工程决策**（别指望静态分析解决一切）。

项目不是「简历装饰」，而是**六级掌握模型（尤其 Level 3～6）在 CS 侧的落地方式**。没有 artifact，就没有掌握证据。

本文提供：分阶段项目清单、每个项目的目标与验收、推荐技术栈、时间估算、项目日志模板、失败案例如何利用、以及与学校课程的衔接。

## 项目设计的总原则 {#principles}

1. **可完成**：第一版应在 2～6 周内可 demo，而非三年神话项目；
2. **可验证**：有测试、有 benchmark、有能复现的输入输出；
3. **可讲述**：5 分钟内说清「我实现了什么、假设是什么、局限是什么」；
4. **可回溯理论**：每个设计点能指回教材章节（CSAPP、Sipser、K&T、TAPL）；
5. **可迭代**：v1 丑但正确，优于 v0 只有设计文档。

避免：克隆大型开源项目当「学习」却无个人决策；复制教程代码改文件名；只有 UI 没有核心机制。

## 第 1 年：数据结构与系统入门 {#year-1-projects}

### P1：基础数据结构库（C 或 Rust）

**目标**：手写动态数组、链表、栈、队列、hash table（链地址或开放寻址）、二叉搜索树或堆。

**理论连接**：CLRS/K&T 复杂度、均摊分析、hash 期望分析（需离散概率基础）。

**验收**：

- 单元测试覆盖边界（空表、满表、重复键、删除后遍历）；
- hash table 统计负载因子与冲突次数；
- valgrind/ASan 无泄漏（C）。

**时间**：4～8 周，每周 3～5 小时。

**Level 对应**：实现正确性 → L3；分析复杂度 → L4；换场景调参 → L6。

### P2：CSAPP 核心 lab 子集

**目标**：至少完成 **datalab**（位运算）、**bomblab**（汇编）、**attacklab**（可选，安全向）、**cachelab**、**malloclab** 中的 **3 个**。

**理论连接**：CSAPP 对应章；机器表示、栈、内存层次、动态分配。

**验收**：

- 官方评分脚本通过；
- 写一篇 lab 报告：关键洞察、踩坑、与课本定理的联系。

**时间**：每个 lab 1～3 周。

### P3：最小 CLI 工具

**目标**：用 C 或 Python 写 `grep`/`wc`/`cat` 简化版，处理文件 I/O、错误码。

**理论连接**：系统 I/O、缓冲、errno。

**验收**：与标准工具在测试集上输出一致；处理大文件不爆内存（流式读）。

## 第 2 年：算法、OS 与网络 {#year-2-projects}

### P4：算法可视化或评测器

**目标**：实现 Dijkstra、MST、区间调度等 2～3 个算法，带可视化或批量测例生成。

**理论连接**：K&T 证明与反例（贪心失败例）。

**验收**：构造让贪心失败的输入；证明文档与代码注释一致。

### P5：xv6 或 rCore 子系统扩展

**目标**：读 xv6 源码，完成 syscall 扩展、简单调度策略修改、或 lazy allocation 实验。

**理论连接**：OS 课进程、页表、中断、锁。

**验收**：能在 QEMU 跑通；能画系统调用路径图；能解释竞态若未加锁会怎样。

**时间**：6～10 周。

### P6：并发练习（线程池、生产者消费者）

**目标**：用 pthread 或语言并发原语实现线程池；压测；用 helgrind/tsan 查竞态。

**理论连接**：CSAPP 并发章；内存模型直觉。

**验收**：吞吐随核数有合理扩展（非完美即可）；无 data race。

## 第 3 年：编译、网络、数据库 {#year-3-projects}

### P7：Tiny Language 编译器（前端 + 可选 IR）

**目标**：词法、语法分析、AST、类型检查（若学 TAPL）、生成栈式字节码或 C。

**理论连接**：Sipser 文法、自动机；TAPL 类型规则；可选对接本仓库 stack-vm 系列。

**验收**：

- 测试程序集：算术、函数、条件、循环；
- 类型错误能报友好信息；
- 文档说明文法歧义如何处理。

**时间**：8～16 周，可分阶段发布 v0.1/v0.2。

### P8：HTTP Server（含静态文件 + 简单 API）

**目标**：TCP listen、解析 HTTP/1.1 请求、路由、并发模型（thread per connection 或 epoll）。

**理论连接**：网络课；CSAPP 并发与 I/O 多路复用。

**验收**：ab/wrk 压测；慢客户端测试；正确 Content-Length/Connection 处理。

### P9：Mini Database / BusTub 类

**目标**：缓冲池、B+ 树（或简化索引）、事务基础、WAL 简化版。

**理论连接**：数据库课；磁盘与缓存一致性。

**验收**：

- 崩溃恢复测试（kill -9 后重启）；
- 能解释 MVCC 或锁表选择与权衡。

**时间**：长期项目，可 3～6 个月迭代。

## 第 4 年及以后：PL、分布式、形式化 {#year-4-projects}

### P10：λ 演算解释器 + 类型检查器

**目标**：实现 untyped λ、再扩展 Simply Typed Lambda Calculus；可选 add let/pairs。

**理论连接**：TAPL；Curry–Howard 预告。

**验收**：类型错误拒绝； Church 编码测试；求值策略（call-by-value）文档化。

### P11：Raft 共识（简化集群）

**目标**：3 节点 Raft，内存状态机，leader 选举与日志复制。

**理论连接**：分布式课；DDIA。

**验收**：分区测试；leader 宕机恢复；不丢已提交日志。

### P12：Lean/Coq 形式化小定理

**目标**：形式化证明自然数加法交换、列表 reverse 性质等。

**理论连接**：逻辑、类型论、证明助手。

**验收**：编译通过；能解释 tactic 与证明对象。

### 方向选修

- **ML**：从零训练线性回归/小型 CNN；读实现对应数学；
- **Crypto**：实现 RSA/ElGamal 玩具版（强调数学基础，非生产安全）；
- **图形/游戏**：shader + 线代迁移。

## 项目与每周 60% 时间 {#time-allocation}

系列第四篇：CS 每周 60% 应落在实现与调试。若一周无项目推进，检查是否被视频/阅读挤占。

建议：**长期项目**每天 1h 比周末 8h 更可持续；**短期 lab** 可周末冲刺。

## 与学校课程作业的关系 {#school-projects}

- 课程大作业若满足验收原则，**算项目**，补日志与理论链接即可；
- 课程作业若太浅（只改几行），**额外加约束**（如加测试、写报告）升格为掌握证据；
- 毕业设计应**对齐地图方向**，避免与四年自学脱节。

## 常见项目失败模式 {#failures}

| 模式 | 表现 | 纠正 |
| --- | --- | --- |
| 教程复制 | 与教程逐行一致 | 关掉教程，从 spec 自己写接口 |
| 永远 v0 | 设计三个月无代码 | 两周内必须可运行 hello path |
| 无测试 | 「我手动试过」 | 先写测试再写实现（TDD 可选） |
| 无理论链接 | 只会调 API | 每 PR 写「对应哪一章」 |
| 范围爆炸 | 编译器+IDE+LLVM | 砍到 tiny language |

## 项目展示与反馈 {#showcase}

即使不求职，也应：

- 代码托管 Git（私有亦可）；
- 每项目 README 含 build/run；
- 每季度向同伴或社区做一次 10 分钟 demo；
- 用六级模型自评项目带来的 Level 提升。

## 行动清单 {#action}

1. 根据当前年份，从上文选 **1 个主项目 + 1 个副项目**；
2. 写 `PROJECT.md`，标里程碑与理论链接；
3. 下周末前达到**可运行 v0.1**；
4. 把项目时间计入每周「做题/实现 60%」账单。

## 结语 {#closing}

CS 的自学尊严在键盘与调试器里。你将来读 DDIA、读论文、设计系统，靠的不是「看过」，而是「做过类似的东西所以相信作者在说什么」。下一篇：**双轨节拍**——数学项目与 CS 项目如何在一周里并行而不精神分裂。

## 误区不是道德失败，是系统设计失败 {#intro}

自学六年，大多数人不是被某一章定理打败，而是被**重复出现的节奏误区**慢慢磨掉：书单越来越长、掌握证据为零、焦虑与愧疚交替，最后停摆三个月。误区往往披着「勤奋」的外衣——每天在读、在记笔记、在刷题——但地图不增长。

本文集中讲解蓝图与系列前文反复提到的**三个核心误区**（串行读完、追求页数、理论/工程偏科），并扩展另外七个常见陷阱：过早抽象、横向比较、完美主义讲义、视频依赖、考试幻觉、无限开新书、忽视回顾与 Redo。每个误区包含：**表现 → 根因 → 纠正 → 恢复时间预期**。

理解误区是为了改**系统**，不是改人格。

## 误区一：按书序串行，一本读完再开下一本 {#pitfall-serial}

### 表现

- 「Hammack 没做完，绝不碰 MCS」；
- Axler 停在第 3 章半年，因为「想做完再开 Abbott」；
- CSAPP 读完才允许写项目，结果永远在读 Part I。

### 根因

把自学误当成**单机 RPG 线性关卡**；害怕「基础不牢」却用**完成度**代替**掌握度**；学校先修表内化过深。

### 为什么有害

不同分支**互相供给动机**。只啃证明书三个月无 CS 实践，容易怀疑「学这些何用」；只读 CSAPP 不做数学习题，算法分析永远停在 `O(n)` 口号。并行是地图的默认姿势（系列第三篇）。

### 纠正

1. 采用**四柱 + 双轨**（系列第二、八篇）：每周数学轨与 CS 轨都有触点；
2. 单本书允许**战略性跳跃**：Hammack 归纳法扎实后，MCS 图论可并行；
3. 用**掌握证据**判断能否开新书，而非章数百分比。

### 恢复

若已串行卡住 3 个月+：选 CS 小项目 2 周冲刺恢复动力，同时 Hammack 维持每周 2h Redo，**不从头重读**。

## 误区二：追求「读完」与页数进度 {#pitfall-pages}

### 表现

- 笔记写「本月读完 400 页」；
- 朋友圈打卡「Axler 第二遍」但无一道独立证明；
- 以「书翻过一遍」为年度成就。

### 根因

页数可量化，掌握难量化；社交媒体奖励可见进度；缺少六级模型与掌握证据习惯。

### 为什么有害

**熟悉感 ≠ 掌握。** 快速翻书产生流畅错觉（系列第五篇）。无习题、无 Redo、无延迟测试的「读完」，在地图上相当于**未探索迷雾**。

### 纠正

1. 改记录为「我现在能做什么」（系列第六篇模板）；
2. 每章绑定**最少题量**：例如核心章 ≥10 道独立证明/实现；
3. 章末白纸 + 两周延迟测试；
4. 年度复盘问「哪些概念 Level 3+」，而非「读了哪些书」。

### 恢复

对「已读完」的书做**审计周**：随机抽 5 章做延迟测试；未过的章标为「未学」，回补而非自欺。

## 误区三：理论/工程偏科 {#pitfall-imbalance}

### 表现 A：纯理论偏科

- 证明很强，不会 gdb；
- 能讲范畴论名词，没写过 malloc；
- 鄙视「工程细节」，但读不懂真实系统论文。

### 表现 B：纯工程偏科

- LeetCode 两千题，说不清 Master theorem；
- 能搭 K8s，不知 CAP 证明直觉；
- 「类型系统没用，动态语言够」直到维护噩梦。

### 根因

天赋与兴趣单边；学校路径单一；把地图当成「选边站」而非交叉学科。

### 为什么有害

现代 CS 站在交叉点（系列第一篇）。理论偏科失去**可验证性**；工程偏科失去**可扩展性**——新框架出现时只能重新搬砖。

### 纠正

- **四柱强制**：即使爱证明，也保 CSAPP + 项目；即使爱代码，也保 Hammack + 核心证明；
- 用**交叉回顾**（系列第八篇）每周找一面镜子；
- 选职业方向时**加深一轨，维持另一轨最低剂量**（每月 4h）。

### 恢复

理论偏科者：下一季度 CS 重周，主项目 malloc 或 HTTP server；工程偏科者：数学重周，Abbott + K&T 证明题，**禁刷题平台 2 周**。

## 误区四：过早抽象（范畴论/HoTT/ZFC 第一年） {#pitfall-early-abstraction}

### 表现

- 大一读 Riehl，functor 不知在抽象什么；
- HoTT 当「最新数学」先学，抽代拓扑为零；
- 沉迷哲学争论「数学对象本体论」，却不做习题。

### 根因

名词高级感；焦虑错过前沿；把基础方案当成学科本身。

### 纠正

遵循认知链：**计算→证明→结构→映射→抽象→基础**（系列第一篇）。第四年再系统范畴；HoTT 需逻辑+拓扑+类型论汇合。

### 恢复

暂停抽象书，回到 Pinter 或 Axler 一章，做 10 道 Level 3 题，重建「抽象从何来」的体验。

## 误区五：横向比较与 FOMO {#pitfall-fomo}

### 表现

- 「同学大二在学机器学习论文」→ 自己也跳；
- 社群晒书单长度 → 焦虑加书；
- 忽视自己四柱漏洞。

### 根因

可见性偏差；把地图当竞赛；缺少个人北极星问题（系列第一篇）。

### 纠正

1. 重读笔记本首页「终点问题」；
2. 只做**掌握证据对比**：我能否 Level 3 证明子空间？而非「他学了啥」；
3. 社交媒体学习计划**静音**或改为输出掌握证据。

## 误区六：完美主义讲义与笔记 {#pitfall-notes}

### 表现

- Notion 排版 3 小时，做题 20 分钟；
- LaTeX 笔记精美无人读；
- 「等笔记体系建好再开始」。

### 根因

制作笔记的**即时成就感**高于做题痛苦；把准备当成学习。

### 纠正

- 笔记限在回顾 20% 块内；
- 粗糙 bullet + 错题本足够；
- **先脏后净**：Level 3 后再整理「干净版」总结。

## 误区七：视频/MOOC 依赖 {#pitfall-video}

### 表现

- 每周 10h 视频，0h 证明；
- 倍速刷课当完成；
- 离开视频不会做同类题。

### 根因

被动输入舒适；误以为「老师讲懂 = 我懂了」。

### 纠正

**每集视频后绑定最少 3 题或 1 小时 lab**；视频算「阅读 20%」，不能占 60%。

## 误区八：考试幻觉 {#pitfall-exam}

### 表现

- 期末 90 分，两周后全忘；
- 开卷找公式能过，闭卷证明为零；
- 把考试成绩等同于地图进度。

### 根因

考试测**短期提取+套路**，与六级 Level 3～6 不完全重合。

### 纠正

考试前后用**延迟测试**；考高分仍对核心章做 Redo；自学以掌握证据为准，成绩作参考。

## 误区九：无限开新书，从不回补 {#pitfall-never-review}

### 表现

- 书架 20 本各读 30%；
- 无 Redo、无白纸、无延迟测试；
- 每年「从新开始」。

### 根因

开新书新鲜感；回补痛苦；缺乏第五篇护栏制度。

### 纠正

**新书禁令规则**：若活跃书 >2 本数学 + 2 本 CS，禁止买/开新书直到一本达到「章级掌握证据完成」；每周五 Redo 夜不可取消。

## 误区十：忽视睡眠与可持续节拍 {#pitfall-burnout}

### 表现

- 假期每天 12h 后停摆 2 月；
- 熬夜证明，次日全忘；
- 把六年地图用六个月自杀式冲刺。

### 根因

低估长期项目；把自律当自虐。

### 纠正

系列第四篇：可持续 > 峰值；每周至少 1 轻量日；季度审计总小时与「做」的比例。

## 误区之间的级联 {#cascade}

常见链条：

```text
FOMO → 开太多书 → 串行/页数焦虑 → 视频/笔记逃避做题 → 假进度 → 挫败停摆
```

打断任意一环即可。最有效断点：**强制掌握证据 + 周五 Redo + 一本主教材**。

## 自检问卷（每月） {#monthly-quiz}

1. 我是否在等「一本书做完」才开下一本？
2. 上周记录的是页数还是能做什么？
3. 过去两周是否有独立证明或 lab commit？
4. 是否因别人学什么而改计划？
5. 活跃教材是否超过 4 本？
6. 是否有一轨超过 3 周零进展？

任一项「是」→ 对照上文纠错。

## 从误区恢复的一周急救包 {#recovery-kit}

**不要**自责式「从零重来」。执行：

| 天 | 行动 |
| --- | --- |
| D1 | 列活跃书/项目，砍到 数学1+CS1 |
| D2 | 对保留数学书做 1 章延迟测试 |
| D3 | 对保留 CS 项目跑通最小 demo |
| D4 | 写 3 条掌握证据 |
| D5 | Redo 3 道旧题 |
| D6 | 交叉回顾 1h |
| D7 | 定下周双轨模板（系列第八篇） |

## 与自责和解：地图是六年 {#mindset}

误区会出现，反复出现。六年路线不是「永不犯错」，而是**有制度把偏离拉回**。护栏、六级、活文档就是拉回机制。发现误区当天，改系统而非宣布「我不适合自学」。

## 行动清单 {#action}

1. 完成月度自检问卷；
2. 标出你当前最严重的 1 个误区；
3. 写一条具体纠正规则（可贴在桌前）；
4. 若已级联停摆，启动急救包 D1。

## 结语 {#closing}

三个核心误区——串行、刷页数、偏科——是地图上的沼泽。其余七个是沼泽旁的岔路。识别它们，不等于免疫，但你会更快拔出脚。最后一篇：**活文档**——如何让路线图随你的掌握证据一起生长。

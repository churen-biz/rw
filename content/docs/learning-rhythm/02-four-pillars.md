## 为什么是「四根柱子」而不是二十门课？ {#why-four}

长期自学最容易犯的启动错误，是**同时打开太多教材**。蓝图里列出的书单，从 Hammack 到 HoTT Book，从 MCS 到 Sipser，从 CSAPP 到分布式系统，加起来足以让人瘫痪。「四根柱子」是一种**战略性的简化**：在你还没有建立证明习惯、结构直觉、算法思维和系统视角之前，其他内容（范畴论、集合论公理化、HoTT、高级分布式）大多无法真正进入长期记忆，只会制造「我见过这个名词」的虚假安全感。

四根柱子分别是：

1. **证明与离散数学**——学会数学的语言与 CS 的离散世界；
2. **连续数学（线代 + 微积分/分析）**——第一次系统接触「结构」与「极限/连续」的严格含义；
3. **算法与计算理论**——从「会写代码」升级到「问题→算法→正确性→复杂度」；
4. **计算机系统**——从「程序在抽象机器上跑」升级到「源码如何成为机器行为」。

这四块覆盖了现代 CS 教育核心的「数学语言 + 连续/离散 + 理论 + 系统」。概率、抽象代数、拓扑、数理逻辑、数据库、网络、PL 等，是**在第一年与第二年逐步接入的副线与扩展**，而不是与四柱同时抢第一优先级。记住认知升级链：**计算 → 证明 → 结构 → 映射 → 抽象 → 基础**。四根柱子对应的是前四步的实体支撑；没有它们，后面的「抽象」与「基础」是空中楼阁。

本文将逐柱展开：学什么、用什么书、如何与学校课并行、第一年的里程碑、常见失败模式，以及如何用「掌握证据」而非「读了多少章」来追踪进度。

## 第一柱：证明与离散数学 {#pillar-proof-discrete}

### 为什么是第一优先级

几乎所有后续数学与理论 CS 都假设你已经习惯：读定义、区分充分必要、使用全称与存在量词、写直接证明/反证/归纳、处理集合/关系/函数/等价类。不会这些，Axler 里的「设 $T \in \mathcal{L}(V,W)$」你会停在符号层；Sipser 里的「构造归约」你会以为只是背套路；甚至 MCS 里的图论证明也会变成死记硬背。

离散数学则是 CS 的「原生地形」。CS 里大量对象是图、树、字符串、置换、有限集上的组合，而不是 $\mathbb{R}\to\mathbb{R}$ 的函数。算法分析里的渐近符号、计数、概率期望、状态机，都建立在离散结构上。

### 推荐路径与书本分工

**证明入门：**

- **Richard Hammack — *Book of Proof***：第一主教材，自学友好，免费电子版易得。覆盖逻辑、集合、函数、关系、多种证明方法、归纳法。
- **Daniel Velleman — *How to Prove It***：第二遍系统巩固，集合-逻辑-证明的结构更清晰，适合 Hammack 做完后刷一遍查漏补缺。

顺序：**Hammack → Velleman**。时间紧只能选一本时，**选 Hammack**。

**离散与 CS 数学桥梁：**

- **Lehman, Leighton & Meyer — *Mathematics for Computer Science*（MCS）**：MIT OCW 有完整课程、习题、考试。覆盖证明、图、状态机、渐近分析、计数、离散概率等，是「证明 → CS 数学」的最佳桥梁之一。
- **Kenneth Rosen — *Discrete Mathematics and Its Applications***：大部头、例题多，适合作补充与查阅。

若 Hammack 与 MCS 并行：Hammack 专注「证明手感」；MCS 专注「把这些用在 CS 对象上」。每周不必严格按书序同步，但应保证**每周都有证明题落在纸面上**。

### 第一年里程碑（证明与离散）

- 能独立写：直接证明、逆否、反证、数学归纳与强归纳；
- 能处理：集合运算、笛卡尔积、关系、等价类、函数的单射/满射/双射；
- 能读：简单图论定义与最短路径、树的性质、基本计数原理；
- 能写：$O,\Omega,\Theta$ 的严格定义与简单算法的渐近分析；
- MCS 中离散概率基础：期望、方差、简单随机变量的计算。

### 常见失败模式

- **只读证明不动笔**：数学教材不做题等于没学（系列第四篇会量化时间比例）。
- **跳过逻辑语言 rushed 进图论**：结果图论证明看不懂「为什么可以这样归纳」。
- **把 MCS 当百科全书从头读到尾**：应按 CS 节奏选章，与算法、编程课交叉。

### 掌握证据示例

```text
Proof & Discrete — Induction
✓ 能陈述数学归纳法原理
✓ 能对 divisibility / inequality 类型题独立归纳
✓ 能解释 base case 与 inductive step 各自保证什么
△ strong induction 与 weak induction 的切换还不熟练
✗ graph induction on trees 仍需提示
```

## 第二柱：连续数学（线代 + 微积分/分析） {#pillar-continuous}

### 线代：第一次真正认识「结构」

学校线代课常从行列式、矩阵运算、解方程组开始。地图推荐 **Sheldon Axler — *Linear Algebra Done Right***（第四版官方 Open Access）作为**结构观**主教材：向量空间、线性映射、特征值、对角化，强调「向量不一定是 $\mathbb{R}^n$ 里的列」。

补充：**Friedberg, Insel & Spence — *Linear Algebra*** 传统全面，适合查漏补缺与计算练习。

策略：**Axler 建立结构思想 + Friedberg 补计算与题型**。

主线概念链：向量空间 → 子空间 → 线性组合 → span → 线性无关 → 基 → 维数 → 线性映射 → 核与像 → 特征值/特征向量 → 对角化 → 同构。

与学校线代并行时：学校作业练计算；Axler 习题练证明与概念。遇到「同一个东西两种语言」，正是迁移练习的好机会。

### 分析：把微积分重建一遍

学校高数/微积分通常先教规则：求导、积分技巧、泰勒展开。数学分析问的是：**极限为什么存在、连续如何定义、微分与积分为何合理**。主线：实数完备性 → 序列 → 极限 → 连续 → 导数 → 积分，核心语言是 **ε-δ**。

- **Stephen Abbott — *Understanding Analysis***：第一次自学严格分析的首选，动机与直觉好。
- **Walter Rudin — *Principles of Mathematical Analysis*（Baby Rudin）**：第二遍精炼提高，不建议第一次直接啃。

顺序：**Abbott → Rudin**。第一年可以：学校微积分保证运算；Abbott 从第二章起并行重建严格性。

### 第一年里程碑（连续数学）

- 线代：能定义向量空间、子空间，证明 intersection of subspaces is subspace；理解 linear map 与 matrix 的关系（在有限维下）；
- 线代：能举多项式空间、函数空间作为向量空间的例子；
- 分析：能用 ε-δ 证明简单极限与连续性；理解完备性在证明中的作用；
- 能把导数定义与几何直觉对应，而非只会求导法则。

### 常见失败模式

- **只刷 Axler 不做题**：Axler 的「Done Right」指的是观点正确，不是「只读不做」。
- **跳过学校课只啃 Abbott**：计算手感不足，应用题与物理直觉可能脱节。
- **把线代与分析完全割裂**：分析里的函数空间是线代迁移的天然舞台，可在学 Abbott 后期回看 Axler。

## 第三柱：算法与计算理论 {#pillar-algorithms-theory}

### 数据结构与算法设计

目标不是「会写 quicksort」，而是形成闭环：**Problem → Algorithm → Correctness Proof → Complexity**。

- **Kleinberg & Tardos — *Algorithm Design***：建立算法设计思想（贪心、分治、DP、网络流等），证明与直觉结合好，适合作第一遍算法设计。
- **Thomas H. Cormen 等 — *Introduction to Algorithms*（CLRS）**：百科全书式参考，适合长期查阅与第二遍深化。

并行策略：学校或在线的「数据结构」课提供实现练习；K&T 提供「为什么这样设计、复杂度如何证」。

重点主题：渐近分析、递推关系、排序与搜索、图算法（BFS/DFS/Dijkstra 等）、贪心、分治、动态规划、随机算法入门、比较排序 $\Omega(n\log n)$ 下界。

### 计算理论

核心问题：**计算是什么？什么可计算？什么高效可计算？**

- **Michael Sipser — *Introduction to the Theory of Computation***：本科理论标准教材，从有限自动机、上下文无关文法到图灵机、可判定性、P/NP。

计算理论不宜过早，但也不宜无限推迟。建议在**第二年**系统启动 Sipser，此时你已有：离散数学、基本算法、一定证明能力。第一年可接触自动机与正则语言思想，为编译、lexer 打基础。

### 第一年 vs 第二年分工

| 时间 | 算法 | 计算理论 |
| --- | --- | --- |
| 第一年 | 数据结构实现 + K&T 前半或选章 | 正则/自动机概念（可选） |
| 第二年 | K&T 深化 + CLRS 查阅 | Sipser 系统学习 |

### 常见失败模式

- **LeetCode 替代教材**：题型熟练 ≠ 能证明正确性与复杂度。
- **只背 NP 完全定义**：没有亲手做过归约题，考试时仍不会。
- **忽略下界与信息论论证**：不理解「比较排序为何 n log n」。

## 第四柱：计算机系统 {#pillar-systems}

### 为什么系统必须占一柱

纯理论 CS 可以讨论图灵机；纯工程可以复制框架代码。但**真正理解现代软件栈**，必须回答：源码如何变成机器指令？CPU、缓存、内存如何协作？进程、线程、虚拟内存、系统调用是什么？I/O 与网络如何进入同一图景？这些问题由 **Bryant & O'Hallaron — *Computer Systems: A Programmer's Perspective*（CSAPP）** 从程序员视角串起来。

主线脉络：C 程序 → 汇编 → 处理器体系结构 → 内存层次 → 链接 → 虚拟内存 → 异常与控制流 → I/O → 网络编程基础 → 并发。

### 第一年怎么「入门」而不是「啃完」

CSAPP 大部头，第一年目标是**建立纵向切片**，而非每章满分：

- 完成数据表示、机器码、栈帧相关章节与 lab；
- 理解 cache 与局部性，能解释性能差异；
- 完成 malloc lab 或等价实践（系列第七篇有项目建议）；
- 虚拟内存与进程概念至少过一遍，哪怕并发章先略读。

与编程课并行：用 C 写数据结构，直接服务 CSAPP；避免只会 Python 却读不懂指针与内存。

### 扩展（第二年起）

操作系统专门课、网络、数据库不应被「SQL 语法」替代。理论侧：关系代数；系统侧：B+ 树、缓冲池、事务、MVCC、WAL、复制与共识。这些在第三、四年接入，但第一年系统柱已为你留下「一切最终落在机器上」的直觉。

### 常见失败模式

- **只读 CSAPP 不做 lab**：幻觉最严重的一本书。
- **用 Java 思维读 C**：指针、内存布局、UB 必须亲手踩坑。
- **认为系统课「过时」**：除非你永远只写 CRUD，否则调度、缓存、一致性迟早回来找你。

## 四柱如何并行：一张示例学期表 {#parallel-semester}

假设每学期约 16 周，每周可投入 15～20 小时自学（在职者酌减）。**示例**如下，非唯一答案：

| 周块 | 证明/离散 | 连续数学 | 算法 | 系统 |
| --- | --- | --- | --- | --- |
| 周一晚 | Hammack 1 节 + 2 题 | | K&T 或 DS 实现 | |
| 周二晚 | | Axler 1 节 + 2 题 | | CSAPP 阅读 |
| 周三晚 | MCS 1 节 + 题 | | | CSAPP lab |
| 周四晚 | | 学校高数/作业 | 算法题 1～2 | |
| 周五晚 | 回顾/Redo | | | |
| 周末 | 白纸测试（交替数学轨） | 项目块（C/DS） | lab 冲刺 | |

关键原则：**每周四柱都有触点**，但不必每日四柱齐飞。可以「数学-heavy 周」与「CS-heavy 周」交替，只要一个月内四柱都前进。

## 什么不该现在抢优先级 {#not-now}

以下内容丰富，但**不应与四柱抢第一年主带宽**：

- **ZFC 公理系统、Enderton 集合论全书**——先见过数学结构再回头；
- **Emily Riehl 范畴论**——先见过群同态、线性映射、连续映射；
- **HoTT Book**——需要逻辑、类型论、拓扑、范畴的汇合；
- **分布式共识论文**——需要网络、OS、数据库事务基础；
- **ML 论文堆**——需要概率、线代、优化入门。

不是「永远不学」，而是**现在学了也挂不住**。当焦虑「别人在学 X」时，回到四柱自检表。

## 四柱联合自检（学满一年） {#one-year-review}

一年后，用以下问题诚实自审（详见系列第六篇六级模型）：

**证明与离散：** 能否不看答案完成 Hammack 半数以上章节核心习题？能否用归纳法证明图论简单命题？

**连续数学：** 能否定义向量空间并证明子空间性质？能否用 ε-δ 证明一个非平凡极限？

**算法：** 能否实现并分析 BST、heap、hash table？能否解释一次 DP 的状态定义与转移？

**系统：** 能否解释一次函数调用的栈帧？能否完成 CSAPP 至少两个 lab 并讲清原理？

若有柱明显为「只读过」，不要进入「第二年全面加拓扑、范畴」的扩张，先回补该柱到 Level 3。

## 行动清单 {#action}

1. 为四柱各选**一本**当前主教材（Hammack、Axler、K&T 或学校 DS 课本、CSAPP），写下本周目标章节。
2. 建立四列「掌握证据」笔记（模板见上文与各系列篇）。
3. 把「范畴论/HoTT/分布式」加入**第三年愿望清单**，而不是本周 todo。
4. 阅读系列第三篇《五年参考节拍》，把四柱放入多年时间线。

## 结语 {#closing}

四根柱子不是终身只学四本书，而是**当下最该立住的承重结构**。证明让你读得懂定理；线代让你看得见结构；算法让你会设计可论证的方案；系统让你相信程序真的在机器上运行。柱子立稳后，概率、代数、拓扑、逻辑、数据库、网络、PL 才有地方挂靠。

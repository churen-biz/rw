## 五年规划不是先修表，而是节拍器 {#not-prerequisite-table}

蓝图中的五年表格，经常被误读成「大学培养方案」：第一年只能学左边列，第二年才能碰右边列，否则就是犯规。这种读法会导致两种恶果：**一是人为延迟有用的并行**（例如等线代全部做完才开离散数学）；**二是在某一年过度堆叠**（第二年同时开分析、概率、抽代、算法、OS，每周爆炸）。

正确读法是：五年表是一张**参考节拍器（metronome）**，告诉你「在 4～6 年尺度的地图上，大致什么时候该第一次系统接触某块地形」。它不是：

- 硬性先修锁（不是「没学完 Munkres 禁止碰数据库」）；
- 竞赛排名（不是「别人第三年学范畴论我也必须」）；
- 毕业条件（自学没有教务处）。

你的个人节拍可以拉伸到六年、八年，也可以在某年减速回补；但**前 2～3 年铺地图、后 2～3 年选方向深挖**的节奏建议保留。

本文将逐年展开：数学侧重、CS 侧重、推荐并行方式、该年结束时的自审标准、与学校/工作的协调，以及「回补年」如何处理。

## 总览：五年参考表 {#overview-table}

| 阶段 | 数学侧重 | CS 侧重 |
| --- | --- | --- |
| 第 1 年 | 证明、微积分、线代、离散数学 | Python/C、数据结构、CSAPP 入门 |
| 第 2 年 | 数学分析、概率、抽象代数 | 算法、体系结构、操作系统 |
| 第 3 年 | 拓扑、数理逻辑 | 计算理论、网络、数据库、编译 |
| 第 4 年 | 集合论、范畴论 | PL、分布式系统、复杂性理论 |
| 第 5 年+ | 类型论 / HoTT / 专业方向 | ML / Crypto / PL / Systems / Theory 深入 |

副线「概率/统计/信息」横穿多年：第二年系统学概率，第三年后可接信息论、随机过程、统计学习理论等，按方向选修。

数学主干的逻辑依赖（**逻辑关系，非时间锁**）：

```text
逻辑与证明 → 集合/函数 → 线性代数 → 数学分析 → 抽象代数 → 拓扑
                                      ↓
                         集合论/数理逻辑 → 范畴论 → 类型论/HoTT
```

CS 主干的逻辑依赖：

```text
编程 + 离散 → 数据结构/算法 → 体系结构/系统 → 网络/数据库
                    ↓
              计算理论 / 编译 / PL
                    ↓
              分布式 / 复杂性 / 专业应用
```

**大学阶段应并行推进**——这句话对自学者同样成立。

## 第 1 年：立四柱，铺地基 {#year-1}

### 数学

- **证明**：Hammack 为主，目标至少完成核心章节（逻辑、集合、函数、关系、证明方法、归纳）。
- **线代**：Axler 并行学校线代；建立向量空间观。
- **微积分**：学校课或自学运算；若时间允许，Abbott 前几章预热 ε-δ 思维。
- **离散**：MCS 选章推进（图、计数、渐近、离散概率）。

### CS

- **语言**：Python 快速原型 + **C** 作为系统语言（为 CSAPP 服务）。
- **数据结构**：实现 vector、链表、栈、队列、hash table、BST/heap 至少各一遍。
- **CSAPP**：第一年「入门」——数据表示、机器码、栈、cache、部分 VM lab。

### 并行策略

第一年切忌「Hammack 做完才开 MCS」。建议比例：**证明 30% / 线代+高数 25% / 离散 20% / CS 实践 25%**（时间分配细节见系列第四篇）。

每周至少一次「数学证明落在纸上」+ 一次「C 代码或 lab 推进」。

### 第一年结束自审

- 四柱掌握证据（系列第二篇）是否多数达到 Level 3？
- 能否用 C 写带指针的数据结构且无内存泄漏（或 valgrind 干净）？
- 能否独立证明一道归纳法题并解释 base case 与 inductive step？

若否，**延长第一年节拍**，不要硬进第二年全套分析+抽代+OS。

## 第 2 年：严格化与概率进入 {#year-2}

### 数学

- **数学分析**：Abbott 系统学习；与已学微积分对照重建。
- **概率论**：Blitzstein & Hwang 或 Ross；随机变量、期望、方差、常见分布、LLN/CLT 直觉。
- **抽象代数**：Pinter 入门群/环/域；同态与同构定理的第一次接触。

### CS

- **算法**：Kleinberg & Tardos 深化；CLRS 作参考；复杂度证明与下界。
- **体系结构**：CSAPP 处理器、内存层次、链接深化；可与学校计组并行。
- **操作系统**：进程、线程、调度、同步、虚拟内存；xv6 或等价 lab（系列第七篇）。

### 并行策略

第二年数学量明显上升。**不要三种数学同时「从零开始」**：若第一年 Abbott 未启动，第二年先 Abbott 再抽代，概率可与 Abbott 中后段并行（概率需要微积分/求和基础）。

CS 侧 OS 与算法可共享「并发」主题：算法课讲并行算法直觉，OS 讲线程与锁，互相照亮。

### 第二年结束自审

- 能否用 ε-δ 证明一个非平凡极限？
- 能否计算离散/连续随机变量的期望并解释 LLN？
- 能否陈述群公理并证明一个简单子群命题？
- 能否实现 Dijkstra 并分析复杂度？能否解释进程与线程区别？

## 第 3 年：空间、逻辑与 CS 理论汇合 {#year-3}

### 数学

- **拓扑**：Topology Without Tears → Munkres 选章；开集、连续、紧致、连通、积拓扑、商拓扑。
- **数理逻辑**：一阶逻辑、形式系统、$\vdash$ 与 $\models$、完备性定理陈述、哥德尔不完备的陈述与意义。

### CS

- **计算理论**：Sipser 系统过完；图灵机、可判定性、停机问题、P/NP、归约。
- **网络**：协议栈、TCP/UDP、HTTP；写简单 server（系列第七篇）。
- **数据库**：关系代数 + 存储引擎概念；mini-db 或 BusTub 类项目。
- **编译**：词法/语法/语义入门；tiny language 前端（系列第七篇）。

### 并行策略

第三年是一轮「理论汇合」：逻辑课上的形式系统，与 Sipser 的可计算性、与类型论预告（命题即类型）开始同频。拓扑上的「连续不必依赖距离」，会反哺分析里对连续函数的重新理解。

**风险**：第三年科目多。建议**每学期主攻 2 数学 + 2 CS**，其余略读或推迟半年。例如秋季：拓扑 + Sipser + 网络；春季：逻辑 + 数据库 + 编译。

### 第三年结束自审

- 能否用开集定义说明连续映射？
- 能否区分语法推导与语义蕴涵？
- 能否从图灵机陈述停机问题不可判定？
- 能否解释 B+ 树与 WAL 在事务中的作用？

## 第 4 年：基础回头与系统扩展 {#year-4}

### 数学

- **集合论**：Halmos → Enderton 选章；可数/不可数、基数、序数、选择公理、Russell 悖论。
- **范畴论**：Riehl 或 Awodey；在见过群、向量空间、拓扑后，functor 与 natural transformation 才有落点。

### CS

- **编程语言**：TAPL；λ 演算、操作语义、类型系统、Curry–Howard 连接。
- **分布式系统**：复制、共识（Raft）、分布式事务难点；读 DDIA 类教材。
- **复杂性理论**：若 Sipser 已扎实，可深化空间复杂度、近似、随机复杂度等选修。

### 并行策略

第四年适合回答「我想往哪个方向挖」。若偏 PL/形式化，TAPL + 范畴 + 逻辑回顾应占主带宽；若偏系统，分布式 + 数据库深化 + 内核/xv6 二周目；若偏理论，复杂性 + 密码学数学基础。

**不要四年每年都平均撒胡椒面**——第四年起应出现**主副线之分**：主线占 60～70% 时间，副线维持阅读不中断即可。

## 第 5 年及以后：选方向往地下挖 {#year-5-plus}

数学方向示例：

- **类型论 / HoTT**：依赖类型、单值公理、同伦论背景（需拓扑、范畴、逻辑齐全）。
- **代数 / 代数拓扑**：若抽代与拓扑扎实，可进 Galois、代数拓扑、表示论等。
- **分析 / 概率深化**：实分析、测度论、随机过程、统计理论。

CS 方向示例：

- **ML 理论**：线性模型理论、优化、泛化界、概率图模型。
- **Crypto**：数论、代数、概率、复杂性交叉。
- **PL**：编译器全栈、类型系统设计、形式化验证（Lean/Coq）。
- **Systems**：内核、数据库内核、分布式存储、高性能网络。

第五年不是「学完」，而是**在地图上选 1～2 个盆地持续下挖**，同时用活文档（系列第十篇）维护与其他区域的连接。

## 并行 vs 串行：决策规则 {#parallel-rules}

何时**应该并行**：

- 不同领域提供**互相动机**（线代 + 编程写矩阵运算；证明 + 算法正确性）。
- 其中一门是**计算/实现导向**，可调剂纯证明疲劳。
- 两本书处于**不同认知层级**（学校高数运算 + Abbott 严格性）。

何时**暂时串行**（减少并行）：

- 某门课明显**基础不牢**（归纳法都不会，却开图论证明）。
- 个人生活**带宽骤降**（考试季、项目冲刺），宁可减慢节拍也不四开新书。
- 新书与旧书**符号系统冲突**且无人指导（极少见；多数情况可并行）。

何时**延后**：

- 蓝图标明「不宜过早」的内容（HoTT、ZFC 全书、高级范畴）。
- 自检 Level 未达 3 却想开下一层抽象。

## 回补年（Gap Year）与减速 {#gap-year}

不是每个人都能每年匀速前进。「回补年」是诚实策略：

- **数学回补年**：专攻证明与分析漏洞，CS 维持最小项目（如每周 4 小时 C）。
- **CS 回补年**：专攻 CSAPP + OS lab，数学维持 Hammack/Velleman 复习。

回补不是失败，而是**地图上的填洞工程**。活文档应记录：回补原因、目标章节、恢复全面节拍的条件。

## 季度节拍模板 {#quarter-template}

每季度初（约 12 周），填一张表：

```text
本季度主旋律：例如「Abbott Ch3-5 + Sipser Part1 + CSAPP VM」
本季度副线：例如「MCS 概率章 + 每周 2 算法题」
本季度项目：例如「malloc lab」
本季度不做：例如「不新开范畴论」
季度末自审日期：YYYY-MM-DD
```

季度末用六级模型抽查 3 个概念、延迟测试 1 个旧章、更新活文档。

## 结语 {#closing}

五年表的价值在于**防止两件事**：过早深挖抽象基础，以及永远停留在入门却不承认。并行是默认姿势，串行是战术性收缩。前 2～3 年你应在地图上认出大多数「大陆名称」；后 2～3 年你应能向他人讲清「我为什么选这个方向、它依赖哪些大陆」。

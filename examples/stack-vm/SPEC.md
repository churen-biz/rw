# SVM 1.0 教学规格

SVM 是本教程配套的栈式虚拟机。它的目标是用尽量少的 C11 代码，完整展示现代语言 VM 的功能边界，而不是兼容 JVM、V8 或 Go 的既有二进制格式。

## “完整”的验收定义

最终参考实现必须同时满足以下条件：

1. 模块在执行前经过解码和控制流类型验证；
2. 支持函数调用、递归、对象、数组、闭包和动态带标签值；
3. 支持异常处理表、跨帧展开和 `defer` 清理；
4. 使用停止世界、非移动、标记清除 GC，并精确扫描 VM 根；
5. 使用协作式任务调度，支持 `spawn`、`await`、channel 和 `select`；
6. 所有宿主访问都经过 capability，且参数和返回值经过检查；
7. 限制指令、堆、栈、任务和宿主调用资源；
8. 非法模块和每种资源超限都有自动化负面测试；
9. 在 macOS Clang 和 Linux GCC 上以 C11、`-Wall -Wextra -Werror` 编译；
10. AddressSanitizer 与 UndefinedBehaviorSanitizer 测试通过。

## 有意不做的事情

- 不读取 Java `.class`、JavaScript 源码或 Go 可执行文件；
- 不实现 JIT、分代 GC、并行 GC、抢占式调度和无锁队列；
- 不复刻任何目标语言的完整标准库或反射协议；
- 不把 C 指针暴露给客体程序；
- 不承诺稳定的生产 ABI。

## 实现里程碑

| 目录/章节 | 可观察结果 | 新增安全性质 |
| --- | --- | --- |
| 01 执行核心 | 计算整数表达式和循环 | 栈、局部变量、跳转边界检查 |
| 02 验证与调用 | 调用递归函数 | 非法控制流和栈类型在执行前被拒绝 |
| 03 受管堆与 GC | 创建对象、数组、闭包并回收 | 句柄、边界、额度与精确根扫描 |
| 04 异常与清理 | 跨函数捕获异常 | 展开过程中 `defer` 恰好执行一次 |
| 05 任务与 channel | 生产者/消费者并发 | 暂停、恢复、关闭、死锁与额度语义确定 |
| 06 capability | 受限同步/异步宿主调用 | 无授权时无法访问宿主资源，调用前计费 |
| 07 二进制模块 | 模块文件编码、加载和验证 | 截断、重叠、溢出和非法 opcode 被拒绝 |
| 08 完整组装 | 从文件加载并运行示例 | 构建、配额和失败路径端到端覆盖 |

每个里程碑都必须有成功测试和至少一个失败测试。正文按测试函数的排列顺序指导实现；最终源码保留全部阶段的可执行测试，第一章另保留独立的最小 `vm.c` 作为从零起点。
